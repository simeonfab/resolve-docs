Which variant fires

Same state, one branch on milestones completed: 0 → variant 1 (pure reassurance), ≥1 → variant 2 (progress acknowledged). Nothing else differs — same slot, same skeleton, same control. Never show an empty checklist.

Motion

Enter: 200ms opacity + 6px rise on the headline, ring and card, staggered 60ms. Ring holds a 3.2s opacity breathe at 0.85→1 — no rotation, because rotation reads as "working now" and it isn't. Ticked rows do not re-animate; they were already ticked in the pending state.

Reduced motion

Breathe removed, ring held at full opacity. Enter becomes a <120ms opacity fade, no translate, no stagger. Copy and layout identical.

Banned here

  • Disabled buttons, retry, "try again"
  • Countdown timers or "resumes in 6h 12m"
  • "X generations remaining", any counter
  • quota · rate limit · API · tokens · capacity
  • Red, warning triangles, apology tone
  • Anything implying paying removes it
